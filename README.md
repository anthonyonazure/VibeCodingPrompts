## ❤️ HealthChecks

Prompts in this category help validate that applications, services, and infrastructure are functioning correctly.

### Common Use Cases

* 🖥️ Service uptime monitoring
* 📡 API availability checks
* 🗄️ Database connectivity validation
* 📊 Performance baselines
* 🔁 Scheduled self-tests
* 🚨 Failure detection logic

### Example Prompt Ideas

* Generate a health check endpoint for a web app
* Create a script to verify service dependencies are running
* Build a scheduled job to test database connectivity
* Produce logging for success and failure states
* Create alert conditions based on response time thresholds

### What Good HealthChecks Should Do

* Fail fast and clearly
* Return simple pass or fail results
* Log useful diagnostics
* Avoid exposing sensitive data
* Be lightweight and fast

## 🔐 Security

Prompts in this category focus on reducing risk, improving posture, and enforcing best practices.

### Common Use Cases

* 🔎 Security audits
* 🔑 Identity and access reviews
* 🧱 Hardening configurations
* 📦 Dependency vulnerability checks
* 🛑 Misconfiguration detection
* 📜 Policy validation

### Example Prompt Ideas

* Generate a security review checklist for a new app
* Create a least privilege access model
* Analyze infrastructure for exposed ports or services
* Suggest secure defaults for authentication flows
* Produce logging and audit trail strategies

### Security Principles

Prompts in this section should encourage:

* Least privilege access
* Secure defaults
* Strong authentication
* Minimal data exposure
* Auditability and traceability

Avoid prompts that:

* Store secrets in plain text
* Disable protections for convenience
* Expose internal system details
